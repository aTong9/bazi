# 八字关系分析系统 M0-M5 开发实施顺序 V1.0

## 0. 基础工程

先实现：

```text
ID与版本
枚举与状态
ResultItem
SourceRecord
EventRecord
Provenance
DecisionLog
统一Schema校验
```

验收条件：

- 能导入10918条运行时记录；
- `global_id`唯一；
- M0、M1—M5源版本可追溯；
- unknown、not_assessed、conditional、stopped可稳定序列化；
- source_id和event_id可以去重。

## 4. 补齐M3

当前必须补建：

```text

M3-STATE

```

在补齐前，所有依赖这些字段的M4/M5输出必须：

```text
status = dependency_pending
confidence 降一级
dependency_flags 明确记录
```

## 6. M5关系适配

```text

→
PARTNER
→

→
BOUND
→

→

→

→

```

验收条件：

- 只有命盘资料时不进入FG3；
- PARTNER不替代EXCHANGE；
- EXCHANGE不覆盖BOUND；
- BOUND不替代REPAIR；
- REPAIR不替代RHYTHM；
- RG01安全失败直接FG0／AF09；
- 核心RG失败最高FG2／AF08；
- FG不是成功概率，AF不是命定结果。
