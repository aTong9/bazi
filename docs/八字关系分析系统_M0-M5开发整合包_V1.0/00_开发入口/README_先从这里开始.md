## 真源规则

- M0机器真源：V1.9核心工作簿。
- M1-M5机器真源：各模块最新原子规则CSV。
- 统一Excel和CSV是开发索引，不无痕替代源文件。
- 旧版本、设计文档、速查手册和校准工作台均保留在`05_原始来源_只读`或`06_历史归档`。

## 当前依赖缺口

- M3-REPAIR、M3-STATE、M3-SYNTH尚未正式完成；
- M1缺少独立SYNTH、JSON和校准闭环；
- D0动态岁运与具体时点模型尚未建设；
- M0-M5规则尚未完成真实案例统计校准。

## 开发边界

本系统不得直接输出：

- 唯一正缘；
- 必然结婚或必然长久；
- 具体婚期、相遇月份或分手日期；
- 伴侣职业、收入、外貌或生肖；
- 医学诊断、用药建议；
- 因适配等级而要求用户进入、继续、原谅或复合。
