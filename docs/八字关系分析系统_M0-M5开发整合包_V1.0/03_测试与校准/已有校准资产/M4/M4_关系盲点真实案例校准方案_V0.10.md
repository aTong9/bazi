# M4 关系盲点真实案例校准方案 V0.10

M4 V0.9 已完成3040条规则，但仍全部待验证。V0.10建立真实案例校准流程，不新增理论规则。

## 硬原则

1. 预测先冻结，反馈后核验。
2. 逐字段、逐规则判断，不用笼统“准/不准”。
3. 对方反馈只写可观察行为，不由命盘补写动机。
4. 同一source_id/event_id只算一次基础证据。
5. E3必须有反馈与复发；E4必须跨事件/跨情境、独立佐证和反例审查。
6. 安全事实优先，暴力、威胁、强迫、跟踪、经济控制停止普通双方循环解释。

## 建议批次

先运行24类结构测试；再做20—30例试点；修订后扩展到80—120例；最后做双人盲评与跨情境验证。

## 当前边界

本阶段只完成校准工作台和方法，尚未录入真实案例，因此不能宣称M4已完成准确率校准。
