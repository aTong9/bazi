# ADR-0004：状态、置信、证据、AF 与 FG 分离

状态：Accepted

日期：2026-08-29

## Context

关系分析同时表达规则是否成立、证据是否充分、现实适配结论及其发布上限。把这些概念压成一个分数，会让未知状态被当作否定、重复证据被重复加权，并让结构信号越权覆盖现实安全事实。

## Decision

- `status` 只描述执行生命周期；`confidence` 只描述证据充分度；`evidenceIds` 保留可追溯事实；
- AF 表达裁决类型，FG 表达允许发布的适配等级，两者不得互相推导或与置信度混用；
- 未知、依赖未完成和不适用均使用显式枚举，不以空值或零分替代；
- 同一 `eventId`、`sourceId` 在一个裁决上下文中只计一次；
- 只有字段权威矩阵指定的模块能够写入对应字段，上层模块只能引用或裁决；
- 报告层只投影已裁决结果，不重新评分。

## Consequences

- API、Schema、测试证据和校准数据必须保留这些独立字段；
- 无现实资料的单盘结果不得越过 FG1，核心现实门未知或证据单方不得越过 FG2；
- 迁移程序必须显式映射旧状态和置信度，禁止按名称猜测。
