# ADR-0006：安全事件使用不可加权硬停止

状态：Accepted

日期：2026-08-29

## Context

同意撤回、暴力、胁迫等现实安全事实不能被吸引力、命理结构或其他正向证据抵消。加权总分会产生不可接受的安全漏报。

## Decision

- RG01 等安全门失败时立即产生 `safety_stop`、`reportStatus=stop`、`FG0` 和 `AF09`；
- 安全事实不参与加权，不允许被其他规则覆盖或降级；
- 安全停止后清空普通适配结论，报告仅保留必要的安全边界与现实支持建议；
- 长文本中的关键安全事实不得因截断或性能优化而跳过；
- 校准周期出现任何 safety miss 时，发布候选门禁失败。

## Consequences

- 安全门优先于所有结构与适配规则；
- 报告契约必须验证安全状态与输出章节的一致性；
- 自动化矩阵和真实案例校准分别验证安全行为。
