# ADR-0011：Pages 离线运行时与原子更新

状态：Accepted

日期：2026-08-30

## Context

GitHub Pages 版本在浏览器内运行完整规则引擎，但首次加载仍依赖网络取得界面资源和规则包。分别缓存资源会产生新界面读取旧规则包的版本混用风险。

## Decision

- 构建结束后从实际 Pages 产物生成 Service Worker，不维护第二份手工资源清单；
- 缓存名由全部产物内容摘要生成，安装时用 `cache.addAll` 原子预缓存界面、规则包和 SPA 回退；
- 任一资源缓存失败时，新 Worker 不接管；激活后仅清理旧的 `bazi-pages-*` 缓存；
- 导航在线时优先取网络，断网时回退同版本 `index.html`；哈希资源和规则包优先读取当前版本缓存；
- 不自动 `skipWaiting`，已打开的看盘会话不会在运行中切换版本。

## Consequences

- 首次成功加载后可离线新建看盘；
- 每个缓存只包含一套完整、可复现的界面与规则快照；
- 新版本会在旧页面全部关闭后接管，更新不会即时打断当前会话。
