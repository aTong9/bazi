# ADR-0008：Catalog 只读、用户结果与校准分域

状态：Accepted

日期：2026-08-29

## Context

权威规则、用户分析结果和带反馈的校准案例具有不同的生命周期与敏感等级。混库存储会让用户数据污染规则真源，也会扩大访问和删除风险。

## Decision

- Catalog 构建后以 digest 目录中的只读 SQLite 提供运行时查询；
- 用户分析结果不写入 Catalog，应用层只持有当前请求所需的裁决数据；
- 校准使用独立 SQLite，匿名码采用带盐哈希，写入前取得同意并记录审计；
- 必须先冻结预测、快照 digest 和代码提交，再录入现实反馈；
- 规则修改只能生成候选，需支持案例、反例和独立二审，不直接回写权威源。

## Consequences

- 三个数据域可分别备份、保留和删除；
- 运行时规则不可被用户请求修改；
- 校准库不进入版本控制，发布只读取汇总门禁结果。
