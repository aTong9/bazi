# ADR-0005：Schema 与语义验证双层门

状态：Accepted

日期：2026-08-29

## Context

JSON Schema 能验证形状和枚举，却不能证明安全停止与 FG0/AF09 一致、字段写入者具有权威，或一条规则进入了允许的运行时模块。

## Decision

- 所有外部输入、快照清单和公开输出先通过版本化 Schema；
- 通过 Schema 后必须再执行语义验证，包括字段权威、状态组合、模块边界、证据去重和安全输出约束；
- 未知字段默认拒绝；兼容载荷只能进入 `wrapped_read_only`，不得参与当前裁决；
- Catalog 构建、API 请求、报告发布和校准导入分别拥有独立验证器；
- 任一层失败即停止发布，并返回稳定错误码或构建错误。

## Consequences

- “结构合法”不等于“业务可发布”；
- Schema 与语义策略均进入可复现快照或提交版本；
- 测试必须覆盖合法结构但非法语义的反例。
