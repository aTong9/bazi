# ADR-0009：状态、置信度与 Excel 日期迁移

状态：Accepted

日期：2026-08-29

## Context

旧工作簿存在状态词、置信度尺度、Excel 日期序列和模板列数差异。直接容错会掩盖歧义，并让旧值进入当前裁决。

## Decision

- 迁移只使用版本化 canonical mapping，不按相似字符串猜测；
- 原始值、来源文件、工作表、行号和迁移结果同时保留；无法映射时标记 unsupported 或 governance；
- Excel 日期按工作簿日期系统显式转换，禁止把裸数字直接解释为 Unix 时间；
- 旧置信度先映射到当前枚举或有界尺度，未知值不得默认为低置信；
- 旧载荷只能以 `wrapped_read_only` 返回，不参与当前规则执行；
- 权威 15 列校准模板是唯一导入合同，旧 17 列模板明确拒绝。

## Consequences

- 所有迁移映射进入 source-package lock 和快照 digest；
- 数据丢失、静默默认和模板自动修补均视为构建失败；
- 更新迁移策略需要新版本映射与回归样本。
