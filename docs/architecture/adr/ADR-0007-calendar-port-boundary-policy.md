# ADR-0007：CalendarPort、历法数据源与交节策略

状态：Accepted（首发范围受限）

日期：2026-08-29

## Context

出生日期到四柱的换算受时区、节气交界、地点和真太阳时策略影响。当前实现能够分析用户明确提供的四柱，但尚未冻结可生产使用的历法库和交节金样。

## Decision

- 领域层只依赖 `CalendarPort` 概念边界，不依赖具体历法库；
- 首个发布候选仅接受完整四柱，并执行干支周期一致性、时区已知和边界候选唯一性检查；
- 缺时柱、时区未知或交界存在多个候选时停止唯一结果发布；边界场景保留双候选，不猜测；
- 日期换算入口在适配器、数据源哈希、真太阳时政策及交节前后金样完成前保持禁用；
- 合成测试可显式绕过历法一致性检查，但该标志不得由生产 API 接收。

## Consequences

- 当前 `calendarVerified=false` 是诚实的范围声明，不代表已完成日期换算；
- 启用日期输入属于后续 ADR 修订，必须记录数据源、版本、时区数据库和边界误差；
- 任何节奏或关系模块不得从当前结果推断具体公历时间。
