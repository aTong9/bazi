# 问真公开名人案例使用规范

问真网页的名人页声明库内有 345 条记录；未登录公开接口在
2026-08-09 返回 35 条。网页读取这些字段：姓名、性别、四柱、站内排盘
时间、分类、是否展示流年、年代和身份简介。

## 可以验证什么

- 将“站内排盘时间 + 性别”输入本地引擎，回放四柱是否与公开记录一致。
- 发现未知时辰（`**`）、录入错误和历法口径差异。
- 作为公开回归样本补充合成边界矩阵。

## 不能验证什么

- 身份简介不是婚恋、财运或性格事件标签，不能据此计算断语准确率。
- 名人出生时辰的来源和考证链未公开，不能视为权威出生证明。
- 古代人物常被平移到现代年份以适应 1801–2099 的排盘区间。例如公开数据
  把朱元璋列为 2048 年出生；这只能复现站内四柱，不能冒充历史公历生日。
- 公开名人数据不能替代匿名真人案例、命理师盲评或规则签署。

## 分级

- `plausible_modern_timestamp`：只有完成独立出生资料考证后才可人工升级为此级；接口解析器不会自动授予。
- `site_replay_only`：年代与站内年份明显不一致，只做站内命盘回放。
- `incomplete_hour`：来源缺时柱，不进入四柱完整匹配率。

原始响应由 `node scripts/collect-wenzhen-celebrities.mjs` 保存到 git 忽略的
`review/api-evidence/`，避免测试依赖第三方在线服务。任何进入固定测试集的
记录都必须同时保存采集日期、来源 URL、上述分级和限制说明。
