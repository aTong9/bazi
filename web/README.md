# 八字关系实验室网页

这是一个纯本地、可静态导出的 React/vinext 网页。四柱、大运、流年、关系报告、
全国行政区搜索和 JSON 模板文案都在浏览器执行，不需要数据库、HTTP API 或密钥。

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: 生成 `dist/client` 静态产物
- `npm run start`: 本地预览生产构建
- `npm test`: 构建并执行离线回归测试
